# オーナー用 受付箱

スマホの GitHub アプリやブラウザで、このフォルダに `.md` ファイルを作るだけで、AIカンパニーに指示が届きます。
翌朝の経営会議で全部読まれ、処理済みのものは `processed/` に移動されます。

## 書き方の例（自由な文章でも大丈夫です）

```
#1 やった。体験メモは guide のファイルに直接書いた
#2 承認
#4 GENHAYL法人で売る
売上 1480 note 初売上
方針：英語版も早めに作りたい
```

- 承認：`#番号 承認`／却下：`#番号 却下 理由`／実行し終えた：`#番号 やった`
- 売上：`売上 金額 メモ`／費用：`費用 金額 メモ`
- それ以外の文章は、CEO への指示として扱われます
