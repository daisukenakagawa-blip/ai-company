## 機能
- 読み込み：CSV/TSV（UTF-8・BOM 有無・Shift_JIS を自動判定）、区切り文字（カンマ・タブ・セミコロン・縦線）を行ごとの個数のそろい方から自動判定、手動でも選べる
- 点検：正しい列数（見出しの列数。見出しなしなら最も多い列数）と違う行、閉じ忘れた「"」、位置のおかしい「"」、セルの中の改行、行末の余分な区切り、制御文字、見出しの空欄・重複、改行コードの混在、読めない文字（�）。行番号はテキストエディタの物理行。「最初に崩れた行」を表示
- 修復（それぞれ選択）：閉じ忘れで何行もつながった行を1行ずつ読み直す／行末の空の列を削除／足りない列を空欄で補う／列が多い行は「要確認に分ける・最後の列につなげる・そのまま残す」／セル内改行を空白に／制御文字の除去
- 保存：直した CSV、要確認の行（元の行番号つき）、点検結果の一覧。UTF-8（BOM 付き／なし）・Shift_JIS、改行は CRLF

## 動作確認（2026-11-20、Node と Playwright / Chromium）
- 関数のテスト（Node、`test.js`）：閉じ忘れの「"」で6行がつながったケースを1行ずつに戻す、正しいセル内改行は残す、行末の空の列の削除、足りない列の補完、列が多い行の3つの扱い、タブ区切り＋CR だけの改行＋NUL、見出しの空欄・重複、Shift_JIS 判定 → すべて想定どおり。20万行（崩れ40行）を約0.4秒で点検
- 画面のテスト（見本データ）：「最初に崩れたのは6行目」、点検結果5件、直した CSV 7行・要確認1行。「最後の列につなげる」に切り替えると要確認0行・8行
- Shift_JIS・CRLF のファイル（「髙田」を含む）を読み込み、直した CSV を保存 → Python の cp932 で読み直して、閉じ忘れの行が1行ずつに戻り、備考のカンマが引用符で囲まれ、髙も保持されていることを確認。点検結果の一覧 CSV も内容一致
- スマホ幅（390px）で設定欄がはみ出す不具合を見つけて修正（グリッドの最小幅）。修正後、商品ページ・ツールとも横スクロールなし。ページのエラーなし
- 公開URLの確認：この実行環境からは pages.dev に接続できず、公開後の表示は直接確認できていない。置き場所・push 先は販売中の他商品と同じ（自動公開）
