## 機能
- .vcf → CSV：vCard 2.1／3.0／4.0、UTF-8・Shift_JIS、Quoted-Printable（CHARSET 指定あり・なし）、行の折り返し、iPhone 形式のラベル（item1.X-ABLabel）、ふりがな（X-PHONETIC-*、SOUND;X-IRMC-N）、写真は読み飛ばし。複数ファイルをまとめて読める
- 列：姓・名・ふりがな・表示名・会社・部署・役職、電話は携帯／自宅／勤務先／FAX／その他の種類別（件数に応じて列を増やす）、メール、住所（種類・郵便番号・都道府県・市区町村・番地・建物名・国・つなげた住所）、誕生日、URL、メモ
- 宛名印刷用の形式（姓・名・郵便番号・住所・建物名・会社名、自宅住所を優先）と「住所がある人だけ」→ atena-hagaki にそのまま入る列名
- そろえる：+81→0、電話を数字だけ、郵便番号のハイフン、ふりがなをひらがな／カタカナ（半角カナも全角に）、空の列を出さない、Excel 用（="…"）
- CSV → .vcf：見出しから項目を自動推測（選び直し可）、氏名1列を空白で姓名に分ける、vCard 3.0・UTF-8・75バイト折り返し・特殊文字のエスケープ。先頭の0が消えた電話、7桁でない郵便番号、読めない誕生日、空行を元の行番号つきで一覧

## 動作確認（2026-11-21、Node と Playwright / Chromium）
- Node：iPhone 風 3.0（折り返し・ラベル・写真・エスケープ）、Android 風 2.1（UTF-8 QP、ソフト改行、半角カナのふりがな）、Shift_JIS の 2.1（髙・SOUND）、4.0（tel: URI・年なし誕生日）、CSV→vCard→再読み込みの往復 → ALL OK
- 画面：4ファイル同時（UTF-8・Shift_JIS 混在）→ 5件、写真1件の注意表示、ふりがなひらがな化、CSV 保存（UTF-8 BOM 付き）、宛名印刷用＋住所ありのみ → 3件。CSV→.vcf（Shift_JIS・空行入り）→ 自動推測が全10列正しい、2件作成、警告の行番号が元ファイルと一致
- 商品ページの無料表示（先頭3件まで）、スマホ幅（390px）で商品ページ・ツールとも横スクロールなし。ページのエラーなし
