連絡先ファイル（.vcf）⇔ CSV 変換

スマホの連絡先を書き出したら「.vcf」というファイルになって、Excel で開くと1列にずらっと文字が並ぶだけ……。このツールに入れると、姓・名・ふりがな・携帯・自宅の電話・メール・郵便番号・住所を列に分けた表（CSV）にします。年賀状の送り先の整理や、名簿の移し替えにお使いください。

お手元の .vcf ファイルを選ぶと、正しく読めるかを先頭3件で表示します（ファイルは送信されません）。

全件の書き出し、CSV の保存、宛名印刷用の形式、ふりがなのそろえ、CSV から .vcf を作る逆変換は、購入後のツールでできます。

できること

  • .vcf → CSV：1人1行の表にします。電話は「携帯」「自宅」「勤務先」「FAX」の種類ごとに列を分け、2つ以上ある人は「携帯1」「携帯2」のように列を増やします。メール・住所も同じです
  • 住所は5つの列に：郵便番号・都道府県・市区町村・番地・建物名に分け、つなげた住所の列も付けます
  • 宛名印刷用の形式：「姓・名・郵便番号・住所・建物名・会社名」だけの列にし、住所が入っている人だけに絞れます。同じお店のはがきの宛名印刷（縦書き）にそのまま入ります
  • そろえる：「+81 90-…」を「090-…」に、郵便番号を「123-4567」に、ふりがなをひらがな・カタカナにそろえられます。半角カナのふりがなも全角にします
  • 古い形式も読める：vCard 2.1・3.0・4.0、UTF-8 と Shift_JIS、Quoted-Printable（「=E5=B1=B1…」のような文字）、折り返された長い行に対応しています。複数のファイルをまとめて入れられます
  • CSV → .vcf：名簿の CSV から、全員分が入った連絡先ファイルを作ります。「氏名」「電話番号」「メールアドレス」などの見出しから列を自動で選び、違っていれば選び直せます。先頭の0が消えた電話番号や、7桁でない郵便番号を一覧にします

使い方の例

こんなときこのツールでの使い方
年賀状・喪中はがきの送り先を、スマホの連絡先から作りたい「宛名印刷用」＋「住所が入っている人だけ」で CSV にし、送らない人の行を消す
お店のお客さんの連絡先を、表で整理したい「すべての項目」で CSV にし、Excel で並べ替える
新しく入ったスタッフのスマホに、取引先の連絡先をまとめて入れたい取引先一覧の CSV から .vcf を作り、スマホで開いて取り込む

よくある困りごと

  • Excel で .vcf を開くと、文字化けする・1列になる：.vcf は表の形ではなく「項目名:値」が縦に並んだファイルです。このツールは1人を1行にまとめ、項目ごとに列を分けます
  • 名前が「=E5=B1=B1=E7=94=B0」のようになっている：古い形式の書き出しでよく使われる書き方（Quoted-Printable）です。このツールは元の文字に戻して読みます
  • 電話番号が「+81」で始まっている：国番号つきの書き方です。チェック1つで「0」から始まる書き方に直せます

できないこと（購入前にご確認ください）

  • スマホや連絡先アプリから .vcf を書き出す操作、取り込む操作は、それぞれのアプリで行ってください（このツールはファイルの変換だけを行います）
  • 写真は書き出しません。SNS のアカウント・メッセンジャーの ID などの項目も CSV には入りません（入らなかった項目は画面に件数を表示します）
  • CSV → .vcf では、住所は1人1件（自宅として）です。連絡先アプリの「グループ」には対応していません
  • 同じ人が二重に登録されていないかの確認はしません（同じお店の「名簿の重複チェック」をお使いください）
  • Excel ファイル（.xlsx）は扱えません。CSV・TSV（UTF-8・Shift_JIS）が対象です。保存する CSV は UTF-8（BOM 付き）です
