CSV を Excel で開くと文字化けするときの直し方

2026-11-21 公開

ネットショップの管理画面や Web サービスからダウンロードした CSV をダブルクリックで開くと、日本語が「縺薙ｓ縺ｫ縺｡縺ｯ」のような文字になってしまう。よくある原因と、Excel の機能だけで直す方法です。

原因：ファイルの文字コードと、Excel の思い込みが違う

日本語の CSV には、主に UTF-8 と Shift_JIS の2つの文字コードがあります。最近の Web サービスの多くは UTF-8 で書き出しますが、日本語版の Excel は、CSV をダブルクリックで開くと Shift_JIS だとみなして読みます。この食い違いで文字化けします。

ただし、UTF-8 の中でも、ファイルの先頭に「BOM」という目印が付いているものは、Excel が UTF-8 だと気づいて正しく開きます。

直し方1：Excel の「データ」から読み込む（ファイルはそのまま）

  1. Excel で空のブックを開き、「データ」タブ →「テキストまたは CSV から」を選ぶ
  2. CSV ファイルを選ぶ
  3. 表示された画面の「元のファイル」を「65001: Unicode (UTF-8)」にする（プレビューの文字化けが直ります）
  4. 「読み込み」を押す

Microsoft 365 などの最近の Windows 版 Excel の手順です。版によって画面の名前が少し違うことがあります。

直し方2：メモ帳で「UTF-8 (BOM 付き)」に保存し直す

  1. CSV を右クリック →「プログラムから開く」→「メモ帳」
  2. 「ファイル」→「名前を付けて保存」
  3. 下の「エンコード」を「UTF-8 (BOM 付き)」にして保存

これで、ダブルクリックでも文字化けせずに開けるようになります（Windows 10 / 11 のメモ帳）。

あわせて起きやすい問題：先頭の0が消える

ダブルクリックで開くと、郵便番号「0600001」が「600001」に、電話番号「09012345678」が「9012345678」に、長い番号が「4.90E+12」になることがあります。Excel が数値だとみなすためです。この状態で上書き保存すると、元の値は戻りません。

直し方1の画面で「データの変換」を押し、その列のデータ型を「テキスト」にしてから読み込むと防げます。

逆に「Shift_JIS の CSV で」と言われたら

取込先のシステムが Shift_JIS しか受け付けないことがあります。日本語版 Excel で「CSV（コンマ区切り）」として保存すると Shift_JIS になりますが、Shift_JIS にない文字（「髙」「﨑」などの一部の漢字や絵文字）は「?」に置き換わります。どの行が置き換わったかは、保存したあとでは分かりません。

文字コード・改行コードの変換（500円・買い切り）は、CSV を Shift_JIS ⇔ UTF-8 に変換し、改行コードもそろえるツールです。Shift_JIS にできない文字が、何行目のどこにあるかを一覧にします。ファイルはブラウザの中だけで処理し、どこにも送信しません。
