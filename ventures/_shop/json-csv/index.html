JSON ⇔ CSV 変換

管理画面の「エクスポート」や API から受け取ったデータが JSON で、Excel では開けない。中身を表で見たい、取引先に CSV で渡したい――。このツールは JSON を入れるだけで、入れ子になった項目を列に広げ、Excel でそのまま開ける CSV にします。逆に、CSV から JSON を作ることもできます。

できること

  • JSON → CSV：{"customer":{"name":"山田"}} のような入れ子の項目を customer.name の列に広げます。列は全件の項目を合わせて作るので、件によって項目がなくても列がずれません
  • 表にする部分を選べる：{"count":3,"orders":[…]} のように一覧が奥に入っている JSON でも、配列を見つけて候補に出します
  • 配列の扱いを選べる：「赤、青」のように1つのセルにまとめる／tags.1・tags.2 のように列に分ける／注文の明細のように1件を明細の数だけの行に展開する（親の項目は各行にくり返し入れます）
  • 桁の大きい ID を丸めない：9007199254740993 のような16桁以上の数字も、書かれたとおりの数字で出力します。先頭の0もそのまま残します
  • JSON Lines（1行に1件の形式）も読めます。JSON の書き方に誤りがあるときは「○行目 ○文字目：「}」の前に余分な「,」があります」のように場所を表示します
  • CSV → JSON：見出しの customer.name を入れ子に戻し、tags.1・tags.2 は配列に戻します。数字・true/false の自動判定（先頭が0の番号は文字のまま）、空欄を "" / null / 書かない から選択、JSON Lines での書き出しにも対応
  • 保存：UTF-8（BOM 付き＝Excel でそのまま開ける／BOM なし）・Shift_JIS、カンマ区切り・タブ区切り。表の結果は Excel にそのまま貼り付けられる形でコピーもできます

使い方の例

元のデータこのツールでの結果
注文の JSON（1件に明細が複数入っている）「明細1つ＝1行」の表にして、注文番号・日付・お客様名を各行に入れた CSV
会員の JSON（住所が address の中に入れ子）address.pref・address.city の列に分かれた CSV
Excel で作った商品一覧の CSVWeb サイトやツールの設定に使える JSON（配列・字下げ付き）

できないこと（購入前にご確認ください）

  • Excel ファイル（.xlsx）・XML・YAML は読み込めません。JSON・JSON Lines・CSV・TSV が対象です
  • JSON の書き方の誤りは場所を表示しますが、自動では直しません
  • API や Web サイトからデータを取ってくる機能はありません。お手元のファイルか、貼り付けたテキストを変換します
  • CSV → JSON で、16桁以上の数字や先頭が0の番号（郵便番号など）がある列は、値が丸められたり0が消えたりしないよう、列ごと文字列として書き出します
  • パソコンの性能にもよりますが、数百MBを超える大きなファイルは時間がかかったり、処理できないことがあります
