GENHAYL の小さな道具

データの整形に役立つ、ブラウザだけで動く小さなツールを販売しています。

使い方ガイド：CSV の文字化け、住所の分割、名簿の重複など、よくある困りごとの直し方（Excel だけでできる方法から紹介しています）

価格改定の一括計算（500円・買い切り・お試し版あり）
商品の表（CSV／Excel）の価格を「5%上げ」「+30円」「分類ごとに違う率」で一度に改定し、10円単位・末尾を8円や80円にそろえる端数処理と消費税（10%・軽減税率8%）の税込・税抜を合わせて計算。改定前後の一覧と値札の差し替えリストを A4 で印刷、元の表に新しい価格の列を足して Excel・CSV 保存。
ピッキングリストと仕分け表（500円・買い切り・お試し版あり）
ネットショップ・受注ソフトの受注明細 CSV／Excel から、品ごとに数を合計して棚番の順（A-2 → A-10 の番号順）に並べたピッキングリスト、注文ごとの仕分け表、品ごとの配分表を A4 で印刷。棚番は商品マスタから品番で付けられ、注文を何件ずつかに分けて作れる。Excel・CSV 保存。
入荷の検品の照合（500円・買い切り・お試し版あり）
注文した明細（発注書・注文履歴）と納品書・出荷明細の CSV／Excel を品番か品名で突き合わせ、数の不足・多すぎ、届いていない品、注文にない品、単価の違いを一覧に。分納の行は合計して比べ、品番の書き違いの疑いも組にして表示。検品表の A4 印刷、Excel・CSV 保存。
部品表の必要数と作れる数（500円・買い切り・お試し版あり）
製品・セットの部品表（構成表）の CSV／Excel から、作る数に必要な部品・材料・中身の数を合計し、在庫と比べて足りない部品を一覧に。在庫で製品ごとにあと何個作れるか・先に足りなくなる部品も表示。半製品のある何段の部品表でも。準備表の A4 印刷、Excel・CSV 保存。
期限の一覧（500円・買い切り・お試し版あり）
契約の更新日・資格の有効期限・保険の満期・車検などの表から、期限切れと30日・90日以内の期限を近い順に一覧に。行ごとの「何日前から」、期限の列が複数ある表、和暦の日付にも対応。A4 印刷・Excel/CSV 保存・カレンダー（.ics）書き出し。
座席表の作成（500円・買い切り・お試し版あり）
会議・研修・試験会場・懇親会の名簿から座席表を作ります。行×列と通路、島型の机の並びに、名簿の順・並べ替え・ランダムで名前を入れ、決めてある席・前の方の席・隣どうしで同じ部署にしない条件にも対応。A4 印刷、受付用の席の一覧、Excel・CSV 保存。
班分け・グループ分け（500円・買い切り・お試し版あり）
研修・行事・イベントの名簿から、人数がそろい、性別・学年・部署などが偏らない班を作ります。同じ班にしない人・する人、前回と同じ顔ぶれを減らす、点数の平均をそろえる条件にも対応。班ごとの名簿を A4 印刷、Excel・CSV 保存。
発注点チェックと発注書（500円・買い切り・お試し版あり）
在庫の表（品名・在庫数・発注点）から、発注が必要な品と発注する数を計算。目標在庫・ケース入数・最小発注数・入荷予定も計算に入れ、仕入先ごとに1枚の発注書を A4 で印刷。Excel・CSV 保存。
面談の日程の割り当て（500円・買い切り・お試し版あり）
個人面談・三者面談・1on1 の希望（第1〜第3希望の日時、○△×の表、都合の悪い日時）から、できるだけ希望どおりで重ならない時間割を作ります。きょうだいは同じ日の続けての枠に。時間割と1人ずつの日時のお知らせを A4 印刷、Excel・CSV 保存。
段階評価のアンケート集計（500円・買い切り・お試し版あり）
「とても満足〜とても不満」「そう思う〜そう思わない」「1〜5」のような段階で答える設問を、設問ごとの人数・割合・平均点と、段階ごとの割合を色の帯で並べた表に。「大変満足」「普通」などの書き方のゆれもまとめ、部署別の表、A4 印刷、Excel・CSV 保存。
複数選択の回答の分割と集計（500円・買い切り・お試し版あり）
申込フォーム・アンケートの表で「駐車場, 託児, 昼食」のように1つの欄に入った複数選択の回答を、選択肢ごとの ○ の列に分け、選択肢ごとの人数と割合を集計。部署・学年などのグループ別の表、印刷、Excel・CSV 保存。
メールアドレス一覧の点検（500円・買い切り・お試し版あり）
名簿・顧客リストのメールアドレスの列を1行ずつ調べ、全角の＠や空白、@ がない・2件入っているなどの形の誤り、＠の後ろのよくある打ち間違い（.co.jo・.con など）の疑い、同じアドレスの重複を一覧に。整えたアドレスに置き換えた表を保存。送信も存在確認もしません。
封筒の宛名印刷（長形3号・角形2号）（500円・買い切り・お試し版あり）
請求書・案内状を送る封筒に、Excel・CSV の住所録から宛名を1通1枚で縦書き印刷。会社名・部署・御中、左下の「請求書在中」、裏面の差出人に対応。
作業時間の集計（500円・買い切り・お試し版あり）
「1:30」「90分」「1.5h」「1時間半」がまざった作業記録の時間を分にそろえ、担当者別・案件別・月別に合計。開始・終了の時刻と休憩からも計算。読めない記録は行番号つきで一覧。印刷・CSV 保存。
商品コードの検査（JAN・ISBN・ITF・UPC）（500円・買い切り・お試し版あり）
商品マスタ・在庫表・書籍リストの番号の列を1行ずつ調べ、チェックデジット（末尾の数字）の違い・桁数の違い・Excel で崩れた番号（4.90E+12・先頭の0の消え・.0）・同じ番号の重複を一覧に。末尾の数字を付けて番号を作ることも。
予約の重なりチェック（500円・買い切り・お試し版あり）
会議室・社用車・貸出品などの予約の一覧から、同じ物で時間が重なっている予約（ダブルブッキング）を組にして一覧に。物ごと・日ごとの空き時間、予約の間隔のチェック、1日の表の印刷。「9:00〜10:30」が1つの列でも読めます。
当番表の自動作成（500円・買い切り・お試し版あり）
メンバーと期間を入れると、出られない曜日・日付を避けて、回数が偏らない当番表を作ります。祝日は自動で除外、1日に複数の係・複数人にも対応。一覧と月ごとのカレンダーで印刷、CSV 保存。
送付状の一括作成（500円・買い切り・お試し版あり）
取引先一覧（Excel・CSV）から、宛先・日付・同封書類を入れた A4 の送付状を1社1枚でまとめて印刷。会社あては御中、担当者あては様を自動で付け分け。
はがきの宛名印刷（縦書き）（980円・買い切り・お試し版あり）
年賀状・喪中はがきの宛名面を、Excel・CSV の住所録から縦書きで印刷。インストール不要で Mac でも使えます。番地の漢数字、連名、差出人、郵便番号の位置補正に対応。
棚卸の記入用シート印刷（500円・買い切り・お試し版あり）
商品一覧（Excel・CSV）から、棚卸で数を書き込む表を A4 に印刷。棚・分類ごとに改ページ、担当者欄・ページ番号つき。数えた数を入力すると、帳簿との差を付けて CSV に保存できます。
名札・席札の一括印刷（500円・買い切り・お試し版あり）
参加者名簿（Excel・CSV）から、名刺サイズの名札や二つ折りの席札を A4 にまとめて印刷。長い名前は札の幅に合わせて自動で詰めます。区分の帯・卓の名前・使いかけ用紙の途中から印刷も。
宛名ラベルの面付け印刷（A4 ラベル用紙）（500円・買い切り・お試し版あり）
Excel・CSV の住所録から、A4 のラベル用紙（10〜44面）に宛名を並べて印刷。寸法は mm で直せて、使いかけの用紙の途中の面からも印刷できます。封筒・DM の発送に。
CSV 表記ゆれ整形（980円・買い切り）
全角/半角、電話番号、郵便番号、和暦の日付、会社名の（株）などをまとめてそろえます。先頭10行まで無料で試せます。
住所の列分割（500円・買い切り）
1列の住所を「都道府県／市区町村／町域・番地／建物名」に分けます。郡・政令指定都市の区にも対応。先頭10件まで無料で試せます。
氏名の姓名分割・ふりがな統一（500円・買い切り）
1列の氏名を「姓／名」に分け、ふりがなを全角カタカナまたはひらがなにそろえます。
2つの CSV の差分比較（980円・買い切り）
先月と今月の名簿・在庫表などを比べ、追加・削除・変更された行とセルを色分けで一覧にします。
複数 CSV の結合（500円・買い切り）
月別・店舗別に分かれた CSV を、見出しの名前で列をそろえて1つにまとめます。元のファイル名の列も付けられます。
大きな CSV の分割（500円・買い切り）
取込上限のあるシステム向けに、行の数・ファイルの大きさ・列の値ごとに分け、見出し付きでまとめて ZIP に保存します。
文字コード・改行コードの変換（500円・買い切り）
CSV やテキストを Shift_JIS ⇔ UTF-8 に変換し、改行コードをそろえます。Shift_JIS にできない文字の場所を一覧にします。
名簿の重複チェック（980円・買い切り）
顧客・会員名簿の二重登録を探します。電話・メールの一致に加え、「(株)」と「株式会社」、「1丁目2番3号」と「1-2-3」、1文字違いの氏名も候補に出します。先頭30行まで無料で試せます。
Excel で壊れた番号の検出と復元（500円・買い切り）
郵便番号・電話番号・JAN などの消えた先頭の0を補い、「4.90E+12」のような指数表記や「1234.0」を見つけて、直せないものは行番号つきで一覧にします。
縦持ち⇔横持ち変換（クロス表）（980円・買い切り）
「日付・商品・数量」の縦長の CSV を、合計行・合計列つきのクロス表（合計・件数・平均など）にします。月が横に並んだ表を1行1件に戻すこともできます。
壊れた CSV の点検と修復（500円・買い切り）
取込で「○行目の列数が違います」と出る CSV の、列数がそろわない行・閉じ忘れた「"」・セルの中の改行を行番号つきで一覧にし、直せるものは直して保存します。
JSON ⇔ CSV 変換（500円・買い切り）
API や管理画面の JSON を、入れ子の項目を列に広げて Excel で開ける CSV にします。明細の配列を行に展開でき、桁の大きい ID も丸めません。CSV から JSON も作れます。
列そろえ（取込形式テンプレート）（980円・買い切り）
CSV の列を選ぶ・並べ替える・名前を変える・つなげる・空の列を足す。整え方を設定ファイルに保存して、毎回同じ取込形式の CSV にできます。
番号の抜け・重複チェック（500円・買い切り）
請求書番号・注文番号などの CSV から、抜けている番号を範囲でまとめて表示し、重複している番号・桁数の違う番号を行番号つきで一覧にします。
営業日の計算（500円・買い切り）
受注日・締め日の CSV に、土日祝・年末年始・独自の休業日を除いた「N営業日後」の日付や、休みなら前の営業日に寄せた支払期日、営業日数の列を足します。1件だけなら商品ページで無料計算できます。
連絡先ファイル（.vcf）⇔ CSV 変換（500円・買い切り）
スマホなどから書き出した連絡先ファイルを、姓・名・ふりがな・電話・メール・住所の列に分けた CSV にします。宛名印刷用の形式、CSV から .vcf を作る逆変換も。先頭3件は商品ページで無料で確かめられます。
年間営業カレンダーの作成・印刷（500円・買い切り・見本は無料）
年と休む曜日、夏季休業・年末年始などを入れると、祝日入りの1年分のカレンダーを A4 1枚にまとめて印刷・PDF 保存できます。店頭の掲示や取引先へのお知らせに。年度（4月始まり）にも対応。
