# 年間営業カレンダーの作成・印刷（eigyo-calendar）

- 状態：**完成（動作確認済み）／販売中（2026-11-21〜）**
- 価格：500円（税込・買い切り）。商品ページで、年・休む曜日・祝日・年末年始を変えた見本（「見本」の透かし入り）を無料で確かめられる
- 誰が・何に困る：来年の営業日カレンダー（店頭掲示・取引先へのお知らせ・教室の配布用）を、祝日を調べながら表計算ソフトで毎年作っている小さな店・事務所・教室
- 時期：年末（11〜12月）に来年分を作る需要がある
- Stripe 登録業種（データ整形API）との関係：日付データ（祝日・休業日）を整えて表・CSV にするブラウザツール。atena-hagaki（印刷）と同じく、ソフトウェアの販売の範囲と判断。オーナーが別の業種と考える場合は知らせてほしい
- 朝会の申し送りへの対応：既存の eigyoubi は CSV に「N営業日後」の列を足すもので、紙面の作成・印刷はしない（重ならない）。祝日の計算は eigyoubi の eigyo.js をそのまま使い、両方の商品ページを相互にリンク。無料の見本付き

## 機能
- 1月・4月（年度）・10月始まりの12か月、日曜始まり／月曜始まり、A4 縦（3×4）／横（4×3）
- 休み：休む曜日、祝日（振替休日・国民の休日を含む）、年末年始（12/29・12/30・12/31〜1/3）、ほかの休業日（「8/13〜8/16」「8/13-16」「12月30日」「2027/5/6」、年の省略は期間内の年で補う。年度の1〜3月は翌年）、祝日でも営業する日、短縮営業の日（▲）。読めない・期間外の日付は警告
- 紙面：見出し（年・年度に合わせて自動）、店名、下の説明（営業時間など）、凡例の名前、色（赤・緑・青・オレンジ・白黒）、祝日名、月ごとの営業日数
- 印刷（@page で A4 の向きを切り替え）、1年分の CSV（UTF-8 BOM 付き）、設定の JSON 保存・読み込み、ブラウザ内の自動保存（使えない環境でも動く）
