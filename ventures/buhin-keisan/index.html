部品表の必要数と作れる数

部品表（製品・セットごとに、使う部品・材料・中身と数を並べた表）から、作る数に必要な部品の数を合計し、在庫と比べて足りない部品を一覧にするツールです。在庫の表を入れると、製品ごとに「いまの在庫であと何個作れるか」と、先に足りなくなる部品も出します。小さな工房・作家・製造業の材料の準備や、ギフトセット・詰め合わせの中身の数の確認に使えます。ソフトのインストールは不要で、いつものブラウザで動きます。

500円（税込・買い切り）

購入する（Stripe）無料のお試し版

お試し版はすべての機能を使えて、部品表と在庫の表はそれぞれ先頭15行までです。決済が終わると、そのまま製品版の画面に移動します。ブックマークしておけば何度でも使えます。

見本のデータ（架空のギフトセットの部品表と在庫）で計算した例。品名・数は説明用のもので、実在の商品・会社とは関係ありません。

こんなときに

  • 「セットAを30個、セットBを12個」作るのに、箱・袋・リボンがそれぞれいくつ要るかを電卓で出している
  • いくつもの製品で同じ部品を使っていて、全部でいくつ足りないのかがすぐ分からない
  • 部品をまとめた半製品（小袋・組立品）があり、その中身まで数えるのが手間
  • 在庫で福袋・詰め合わせがあといくつ作れるか、どの中身が先に切れるかを知りたい

できること

  • 必要数の合計：作る数を製品ごとに入れると、部品ごとに必要な数を合計します。どの製品の分がいくつかの内訳もメモに出します。数は「0.6」（m・kg など）のような小数でも計算します
  • 何段の部品表でも：子の部品がさらに部品でできている（製品 → 半製品 → 部品）ときも、いちばん下の部品まで数えます。半製品の在庫があれば先にそれを使い、足りない分だけ部品から作る計算にできます（切り替え可）
  • 足りない部品：在庫の表と比べて、部品ごとに在庫・不足・在庫の残りを出します。在庫の表にない部品は在庫 0 として数え、その旨を出します
  • 在庫であと何個作れるか：製品ごとに、いまの在庫だけで作れる数と、先に足りなくなる部品を出します（半製品の在庫も使って計算）
  • 表の点検：数が空欄・数字でない行、同じ親と子の組み合わせが2回ある行（数を足して計算）、ある品が自分自身の部品になっている輪を一覧にします
  • 印刷と保存：部品の準備表（準備の確認欄つき）・足りない部品だけ・作れる数の表を A4 で印刷できます。結果は Excel ファイル（.xlsx、「必要数」「作る数」「作れる数」のシート）か CSV で保存できます
  • CSV（UTF-8・Shift_JIS）と Excel ファイル（.xlsx）を読めます。列は見出し（「製品」「部品」「員数」「在庫」など）から自動で選び、違っていたら画面で選び直せます。品番のハイフン・空白、全角・半角の違いは同じとみなします

できないこと（購入前にご確認ください）

  • 部品表そのものは作りません。製品ごとの部品と数の表（CSV・Excel）が必要です
  • 歩留まり・ロス率、最小発注数・入数への切り上げ、リードタイム（いつまでに発注するか）は計算しません。必要数と不足の数までです
  • ケースとバラ、m と cm のような単位の換算はしません。部品表と在庫の表で単位をそろえてください
  • 「作れる数」は製品ごとに、その製品だけを作るとしたときの数です。いくつもの製品を合わせて作るときは「作る数」に入れて「不足」で確かめてください（作る数の最適な組み合わせは出しません）
  • 発注・仕入先への送信の機能はありません
  • スマートフォンでは操作しにくいため、パソコンでお使いください

Excel だけで計算するなら（部品表が1段のとき）

シート「部品表」の A 列に製品、B 列に部品、C 列に員数（1個あたりの数）、シート「作る数」の A 列に製品、B 列に作る数、シート「在庫」の A 列に部品、B 列に在庫数があるとします。

  1. 「部品表」の D2 に =C2*SUMIF(作る数!$A:$A,A2,作る数!$B:$B) と入れて下までコピーすると、行ごとの必要数になります
  2. 部品の一覧（A 列に部品）を作り、B2 に =SUMIF(部品表!$B:$B,A2,部品表!$D:$D) で部品ごとの必要数、C2 に =MAX(0,B2-SUMIF(在庫!$A:$A,A2,在庫!$B:$B)) で不足の数です
  3. 在庫で作れる数は、「部品表」の E2 に =INT(SUMIF(在庫!$A:$A,B2,在庫!$B:$B)/C2) と入れ、=MINIFS(部品表!$E:$E,部品表!$A:$A,"G-A") で製品「G-A」の作れる数です（MINIFS は Excel 2019 以降・Microsoft 365）

このツールが向いているのは、半製品があって部品表が2段以上、半製品の在庫を先に使って数えたい、製品が多く、どの部品が先に切れるかも知りたい、品番の書き方が表ごとに違う、準備表をそのまま印刷したい、といった式だけでは手間のかかるときです。

よくある質問

データはどこかに送られますか？送られません。読み込み・計算・印刷・保存はすべてお使いのブラウザの中で行います。表題などの一部の設定だけをブラウザに保存し、表の中身は保存しません。
部品表はどんな形なら使えますか？1行に「親（製品・セット）」「子（部品・材料・中身）」「親1個に使う子の数」が並んだ表です。名前・単位の列はあってもなくても使えます。親の列が同じ値でまとまっていなくても構いません。
作る数はどこに入れますか？部品表を読むと、いちばん上の製品の一覧が出るので、そこに数を入れます。製品と数の2列の表を貼り付けて入れることもできます。
何行まで使えますか？製品版は行数の制限はありません（製品200・部品表1万行ほどで、1秒前後で計算できることを確かめています）。画面の一覧は500品まで表示し、全部は保存したファイルに入ります。
