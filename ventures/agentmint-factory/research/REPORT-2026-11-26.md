# Phase 1 市場調査（2026-11-26、Apify Store 公式 API）

## 方法
- `GET https://api.apify.com/v2/store`（認証不要）で全 **117,621 件**を取得（約4分）。項目：30日・7日・90日・累計の利用者数、実行回数、評価、レビュー数、価格（方式・主要イベントの単価）
- 価格方式：Pay per event 114,634件・無料 2,987件（Store の現行の表示）
- 失敗率：上位候補 21件について `GET /v2/acts/{id}` の `publicActorRunStats30Days`（成功・失敗・時間切れ・中断）
- 他社サイトのデータ取得の Actor は数えるだけで候補から外した。残りを22分野に分けて集計（`data/store-2026-11-26-clusters.json`）
- 注意：利用者数は「その Actor を動かした人の数」。購入者数・売上ではない。無料プランの利用者の支払いは作者の収益に数えられない（Apify 公式文書）

## 選んだ3商品（収益性の期待順）
1. **Dataset Merge & Dedup**（実装済み）：需要は分野全体で 30日 約930人。最大手が無料だが63.8%失敗している＝品質の空き。原価は計算だけ（外部 API なし）。スクレイパーの後処理として使われるので、Store の検索とインテグレーションから見つかる
2. **画像の変換・圧縮**（sharp）：上位が13.4%失敗・2か月更新なし。需要は小さい（約100人）
3. **PDF の文字抽出**：需要は約300人で単価が高い（$0.003〜0.005/件）が、上位の品質が良く差別化が難しい

## 見送り
- メール検証：需要は最大だが476件の価格競争。SMTP 確認は送信元の評判と迷惑行為の扱いの危険がある
- スクレイピング全般：会社の方針で作らない

## 収益の見込み
予測はしない。分かっているのは、分野全体の30日利用者が約930人で、その一部だけが有料プランの利用者だということだけ。当社が取れる割合は、公開後の実測で判断する
