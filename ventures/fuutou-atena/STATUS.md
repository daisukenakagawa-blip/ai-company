## 機能
- 封筒：長形3号 120×235mm／長形4号 90×205mm／角形2号 240×332mm。印刷時に CSS の @page を封筒の大きさに切り替え、1通1ページ
- 郵便番号：長形は郵便番号枠の位置「上端12mm・右端8mm」（日本郵便「郵便番号・バーコードマニュアル」p05、JIS。許容±1.5mm）。枠の大きさ・間隔ははがきと同じ 5.7×8.0mm・全幅47.7mm。日本郵便の推薦様式「上端18mm・右端18mm」、枠なし（「〒123-4567」と文字）も選べる。角形2号は文字
  - 出典：https://www.post.japanpost.jp/zipcode/zipmanual/p05.html （枠の個別寸法は図のみのため、atena-hagaki と同じ値を使用）
- 表：住所（右端から、長い住所は2列、建物名は下寄せ）→ 会社名・部署 → 氏名（中央・大きく、連名4人まで）。会社名だけは「御中」
- 表の左下に朱色の枠で「請求書在中」「見積書在中」「納品書在中」「領収書在中」「重要書類在中」「履歴書在中」「親展」、自由入力（10文字）
- 裏：差出人（住所・建物・会社名・部署・氏名）を中央より左・下半分に縦書き、郵便番号は文字。表で選んだ通数をまとめて印刷
- 漢数字（「12階」→十二階も対応）、明朝/ゴシック、ずれ補正（mm）、普通紙での枠つき試し刷り。設定・差出人は localStorage に保存
