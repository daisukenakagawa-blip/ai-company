## 機能
- 入力：CSV（UTF-8／Shift_JIS 自動判定、カンマ・タブ）、Excel（.xlsx 等、先頭シート。数値セルは表示ではなく中の数を使う）、貼り付け。番号の列は見出し（JAN・ISBN・バーコード・商品コード等）と中身から自動で選ぶ
- 種類：桁数で自動（8・12・13・14桁、10桁は ISBN）／JAN（13・8）／JAN 13だけ／短縮8だけ／UPC-A／ITF-14・GTIN-14／ISBN（13・10）。見出しが ISBN なら ISBN、JAN なら JAN を自動で選ぶ
- 判定：正しい／正しい（書き方を整えた：全角数字・ハイフン・空白・末尾 .0・先頭 '・「ISBN」・全桁残った指数表記）／チェックデジット違い（正しい末尾と、末尾だけ直した案）／桁数違い／先頭の0が消えた（種類を決めたとき、0 を補うと正しくなるもの）／数字以外／指数表記（桁が省かれ戻せない）／空欄
- 重複：GTIN-14 にそろえて比較（13桁と0付き14桁、ISBN-10 と 13 を同じ番号として数える）
- 注意書き：20〜29 始まりのインストアコード、192 始まりの書籍2段目、978/979 始まり、ISBN-10 に対する13桁
- 末尾の数字を付ける：7・11・12・13桁（GS1）、ISBN 12桁・9桁
- 保存：明細（元の表＋整えた番号・種類・判定・直した案・ISBN-13・同じ番号の行・メモ）を xlsx（全セル文字列）または CSV（UTF-8 BOM 付き）、問題の行だけ CSV。印刷：問題の一覧（A4 縦）
- 表題・表示の切替だけ localStorage に保存。表の中身は保存しない
