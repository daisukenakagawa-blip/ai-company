2. 調べ方

末尾を付ける前の番号（JAN なら12桁、短縮なら7桁、UPC-A なら11桁、ITF-14 なら13桁、ISBN なら12桁か9桁）の列を選んでください。番号そのものの取得（事業者コードの登録）は、このツールではできません。
