## 機能
- JSON → CSV
  - 読み込み：JSON・JSON Lines（自動判定）、UTF-8/Shift_JIS、ファイルまたは貼り付け
  - 自前の JSON 読み取り：数値を書かれたとおりの文字で保つ（16桁以上の ID も丸めない）。誤りは「○行目 ○文字目：「}」の前に余分な「,」があります」のように日本語で場所を表示
  - 表にする部分：JSON の中の配列を探して候補に（例：`{"count":3,"orders":[…]}` → orders）。全体を1行にもできる
  - 入れ子は `customer.name` の列に（つなぎ方 `.` `_` `/`）。列は全件の項目の和集合（初出順）
  - 配列：1つのセルにまとめる（区切り選択、オブジェクトの配列は JSON のまま）／番号で列に（`tags.1`）／行に展開（親の項目を各行にくり返す）／JSON のまま
  - null・true/false・値の中の改行の書き方を選択。保存は UTF-8（BOM 付き/なし）・Shift_JIS、カンマ/タブ。タブ区切りでコピー（Excel に貼り付け）
- CSV → JSON
  - 区切り自動判定、見出しの `.` で入れ子に戻す、`tags.1`・`tags.2` は配列に戻す（後ろの空欄は要素にしない）
  - 型：自動（数値・真偽値。先頭が0の番号や16桁以上の数字がある列は列ごと文字列）／すべて文字列
  - 空欄："" / null / 書かない。1セルの複数値を指定の区切りで配列に
  - 書き出し：字下げ2・4、1行に詰める、JSON Lines
  - 見出しの重複・空欄、列数の多い/少ない行、「a」と「a.b」の衝突を警告

## 動作確認（2026-11-20、Node と Playwright / Chromium）
- 関数のテスト（Node、`test.js`）：奥にある配列の検出、20桁の ID の保持、配列のまとめ・番号列・行への展開、JSON Lines、書き方の誤り5種の場所表示、CSV→JSON の往復（入れ子・配列・セル内改行・先頭0）、列ごとの型判定、衝突の警告 → すべて想定どおり。10万件を約0.4秒
- 画面のテスト（見本の注文 JSON）：表にする部分「orders（3件）」を自動選択、3行×9列。「行に展開する・items」で4行×11列、親の項目が各行にくり返される。9007199254740993 が丸められずに出る
- 保存：UTF-8 BOM 付き → 先頭 EF BB BF。Shift_JIS → Python の cp932 で読み直して内容一致（髙橋・セル内改行・TRUE/FALSE）
- JSON の誤り（`{"a":2,}`）→「2行目 9文字目：「}」の前に余分な「,」があります」。JSON Lines → 自動判定
- CSV → JSON（見本）：入れ子・配列に戻る、郵便番号列は文字列、16桁以上の ID の列は文字列、650.5 は数値。JSON Lines で保存 → OK
- Shift_JIS・タブ区切りの CSV（髙﨑を含む）をファイルで読み込み → 文字コード・区切りを自動判定、「007」は文字列のまま
- 20万件の JSON（約8MB）→ 約0.7秒で表示
- スマホ幅（390px）で商品ページ・ツールとも横スクロールなし。ページのエラーなし
- 公開URLの確認：この実行環境からは pages.dev に接続できず、公開後の表示は直接確認できていない。置き場所・push 先は販売中の他商品と同じ（自動公開）
