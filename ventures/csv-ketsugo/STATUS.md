## 結合の方式
- 1行目を見出しとし、見出しの名前で列をそろえて縦に積む（前後の空白・全角半角・空白の数の違いは同じ列とみなす）
- 列の残し方：「どれかのファイルにある列はすべて残す（ない所は空欄）」／「全ファイルに共通の列だけ残す」
- 元のファイル名の列：左端／右端／付けない。列名は変更可（既存の見出しと同じ名前なら「_結合」を付ける）
- オプション：まったく同じ行を1行にまとめる（ファイル名は比べない）、途中に出てくる見出しと同じ行を外す（既定オン）
- 見出しなしモード：列の位置でそろえる（列数が違う場合は警告）
- ファイルごとに文字コード（UTF-8/Shift_JIS）と区切り（カンマ/タブ）を自動判定。空のファイルは結合に入れず表示で知らせる
- 同じファイルの中で見出しが重複していれば「名前(2)」として別の列にし、警告。見出しより列の多い行は警告

## 動作確認（2026-11-20、Node と Playwright / Chromium）
- 関数のテスト（Node）：列順の違う3ファイル（BOM付き UTF-8・タブ区切り・見出しに末尾空白）、途中の見出し行、重複行、共通列のみ、ファイル名列を右端、見出しなし・列数違い → 期待どおり
- 画面のテスト（9月.csv＝Shift_JIS・3列／10月.csv＝UTF-8 BOM・列順違い・備考列あり・途中に見出し行・セル内改行／2月.tsv＝タブ区切り／empty.csv＝空）：
  - ファイルごとの文字コード・区切り・行数・列数、足りない列「備考」を表示 → OK
  - 空のファイルは「結合に入れていません」と表示 → OK
  - 途中の見出し行を外して警告 → OK
  - 「ファイル名の順に並べる」で 2月 → 9月 → 10月（数字の大きさ順）→ OK
  - 同じ行をまとめる：1行まとめて警告 → OK
  - ダウンロード：UTF-8 BOM付き、カンマ入り・改行入りの値は引用符付き → OK
  - 共通列のみ：「備考」を外して警告 → OK
  - ファイル名列を右端・名前を「金額」に → 「金額_結合」になる → OK
  - 見出しなしモード：列数違いの警告 → OK
  - 「外す」「すべて外す」→ OK
  - 商品ページ・ツール：スマホ幅（390px）で横スクロールなし → OK
  - ページのエラー：なし
