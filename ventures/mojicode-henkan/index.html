文字コード・改行コードの変換

取込先のシステムが「Shift_JIS の CSV のみ」なのに手元のファイルが UTF-8 だった、Excel で開いたら文字化けした、改行コードが違うと言われてエラーになる――そんなときに使うツールです。CSV やテキストファイルを Shift_JIS ⇔ UTF-8 に変換し、改行コードをそろえます。Shift_JIS にできない文字がある場合は、どの行の何文字目かを一覧にします。

できること

  • 文字コードの変換：UTF-8・Shift_JIS・EUC-JP・UTF-16 を読み込み、Shift_JIS、UTF-8（BOM 付き）、UTF-8（BOM なし）で保存します。読み込む文字コードは自動で判定し、手で選び直すこともできます
  • 改行コードの統一：CRLF（Windows）／LF（Mac・Linux）にそろえます。混ざっているファイルも直せます
  • Shift_JIS にできない文字の一覧：絵文字や「𠮷」などの場所を、行・何文字目・前後の文字つきで表示し、CSV で保存できます。その文字は「?」「〓」、削除、好きな文字への置き換えから選べます
  • よくある記号の置き換え：Mac や Web からコピーした「〜」「−」「‖」など、そのままでは Shift_JIS にならない記号を、見た目の近い文字に置き換えます（置き換えた数を表示します）
  • 濁点が分かれた文字をまとめる：Mac で作ったファイルに多い「か」＋「゛」のような文字を「が」の1文字にします
  • 機種依存文字の確認：①・㈱・髙・﨑 などは Windows の Shift_JIS で保存したうえで、取込先が受け付けない場合に備えて場所を一覧にします
  • 複数のファイルをまとめて変換し、ZIP で保存できます。変換前にプレビューで文字化けしていないか確認できます

使い方の例

困っていること選ぶ設定
Web サービスから書き出した CSV を、Shift_JIS しか読めない古いシステムに取り込みたい保存：Shift_JIS／改行：CRLF
UTF-8 の CSV を Excel で開くと文字化けする保存：UTF-8・BOM 付き
Windows で作った Shift_JIS の CSV を、UTF-8 しか受け付けない Web サービスに入れたい保存：UTF-8・BOM なし／改行：LF

できないこと（購入前にご確認ください）

  • Shift_JIS にない文字（絵文字、「𠮷」のような一部の旧字体・異体字など）は、Shift_JIS のファイルには残せません。置き換えるか削除します（どこを置き換えたかは一覧で確認できます）
  • Shift_JIS は Windows で使われている範囲で書き出します。外字（自分で作った文字）や、取込先だけの独自の文字には対応しません
  • EUC-JP・UTF-16 は読み込みのみです（保存は Shift_JIS と UTF-8）
  • 文字コードの自動判定は、短いファイルや英数字が多いファイルでは外れることがあります。その場合はプレビューを見て、読み込む文字コードを選び直してください
  • Excel ファイル（.xlsx）は変換できません。CSV やテキストファイルが対象です
  • 値の中身の整形や、列・行の並べ替えはしません
