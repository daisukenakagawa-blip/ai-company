# 唐揚げ指数（Karaage Index）仕様書 v0.1（2日目／プロダクト）

## コンセプト
**「唐揚げ1皿をつくる原価」で、データのない都市の物価を毎週測る。**
アディスアベバの ZEN KARAAGE の実際の仕入れ値から作る、民間で最速の食品物価指標。

## 2. 公開する指標
- **Karaage Index（KI）**：唐揚げ1皿の原価を、基準週を100として表した値
- **品目別の週次変化率**（鶏・油・粉・卵…）
- **ドル建てKI**：ブルの実勢レートで換算（為替の影響と、物価そのものの動きを分けて見られる）
- **公式CPIとの比較**：エチオピア統計局（ESS）の月次発表と並べて、どちらが先に動いたかを示す

## 3. データ収集（オーナー側の手間：週5分）
1. 店のスタッフが、仕入れのレシートを毎回スマホで撮影する
2. 写真を、決めた共有フォルダ（または Telegram のグループ）に入れる
3. AIが毎週、写真から品目・数量・金額を読み取り、表にして指数を計算する
4. 異常値（桁違い、まとめ買い割引など）はAIが検出して、オーナーに確認を依頼する

レシートが出ない仕入れ先（市場など）は、下の記録用テンプレートに手で書けば足りる。

### 記録テンプレート（`data/purchases.csv`）
```
date,item,unit,quantity,total_birr,supplier_type,note
2026-11-20,chicken,kg,10,,wholesale,
```
（supplier_type: wholesale／market／supermarket）

## 5. 拡張（指数が育ったら）
- 他都市の日本食・飲食店と提携し、各店の仕入れ値を持ち寄る「**Karaage Index Network**」（ナイロビ、ラゴス、ダッカ…）
- 参加店には、匿名化した他都市の比較データを無料で還元する（データを出すと得をする仕組み）

## 6. 守ること
- 推測値や架空の数字は絶対に載せない。データが足りない週は「データ不足」と表示する
- 仕入れ先の名前や、店の取引条件は公開しない
- 投資助言にあたる表現（「買い」「売り」など）はしない
