### 円換算と使える額
- 費用（円）＝ USD × 為替 × 1.13（税10%の可能性＋カードの為替手数料3%を上乗せ）
- 為替は欧州中央銀行の参照レート（frankfurter.app、無料）。取れないときは 165円/ドル（円安側）で計算
- 月 5,000円のうち使うのは 90%（4,500円）まで。残り10%は為替・未反映の請求・税の予備
- 165円・1.13倍なら 4,500円 ≒ **$24**

## Phase B：予算管理の実装（`ops/ai_budget/`）

有料 API は `guarded_call()` を通さないと呼べない（`ai_company/llm.py` の API 呼び出しも差し替え済み）。

| 要件 | 実装 |
|---|---|
| 呼び出し前の見積もり | 入力は文字数＝トークン数（上限寄り）、出力は max_tokens 全部、検索は回数分を足した上限額で判定 |
| 実行ごとの記録 | `ledger.jsonl`：時刻・用途・優先度・モデル・入力/出力/キャッシュのトークン・検索回数・USD・円・為替 |
| 日別・月別の集計 | `python3 ops/ai_budget/budget.py`（月・年・用途別・今日の回数・残り） |
| 50% で通知 | `alerts.json` に記録 → ワークフローで Issue を作る（Phase D で接続） |
| 80% で低優先度を停止 | priority=low を止める |
| 90% で全停止 | 見積もりを足して 90% を超える呼び出しはしない |
| 料金・消費額が分からない | 料金表に無いモデル → 停止。応答に使用量が無い → 上限額で記録し `STOP` を作って以後停止 |
| 無限ループ・再試行・大量消費 | 1回の実行40回・1日300回・1回100円・出力1.6万トークンまで、再試行1回 |
| 同時実行 | ファイルロックの中で判定→呼び出し→記録。ワークフローも1本ずつにする |
| 用途別の配分 | `allocation.json`（AI が変えてよい。合計が 5,000円でなければ停止） |
| AI が上限を変えられない | `limits.json` の SHA-256 を、**オーナーだけが設定できる GitHub の変数** `AI_BUDGET_LIMITS_SHA256` と照合。未設定・不一致なら有料 API は動かない |
| 緊急停止 | `ops/ai_budget/STOP` を置く（iPhone の GitHub アプリからでも作れる）か、GitHub の変数 `AI_KILL_SWITCH=1` |
| API キーの管理 | GitHub の Secrets（`ANTHROPIC_API_KEY`）だけに置く。リポジトリ・ログに書かない |

試験：`python3 ops/ai_budget/test_budget.py` → **15件すべて合格**（偽のクライアントで、有料 API は呼んでいない）。確かめたこと：記録の金額、ハッシュ未設定・不一致で停止、緊急停止、料金表に無いモデル、90% で停止、80% で低優先度だけ停止、用途の配分、配分の合計違い、1回の上限、ループの上限、使用量なしで停止、50% の通知、為替の既定値、同時実行で上限を超えない、出力トークンの上限。

## 正直な限界
- この仕組みの外（Console で直接使う、別のキー）の利用は数えられない。**本当の最後の歯止めは Anthropic Console の月の使用上限**（オーナーの設定）
- `limits.json` の照合は、AI がワークフローを書き換えれば外せてしまう。AI はそれをしない規則にするが、技術的に絶対ではない → Console の上限と併用する
- 実際の請求額（税・為替を含む）は Console の請求書でしか分からない。月1回、記録との差を確かめる
