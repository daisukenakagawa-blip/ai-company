## 1. 契約に付属する API クレジット（公式文書で確認）
出典：https://platform.claude.com/docs/en/about-claude/api-credits-for-subscribers （2026-11-27 確認）
- 対象：Max（月 $100）、Ultra（月 $200）、Team（Standard 1席 $20・Premium 1席 $100、合計 $500 まで）。**Pro・Free・Enterprise は対象外**
- 受け取り方：claude.ai の 設定 → 請求（Team は 組織設定 → 請求）の「API credits」で、受け取る Console の組織を選び、規約に同意して連携。Console の請求ページの「Promotional credits」に表示。契約から7日後から
- 使える範囲：Claude API・Managed Agents・Agent SDK・Console の Playground（Claude Code とクラウド各社は対象外）
- **支払い方法の登録は不要**。毎月の請求周期の終わりに失効（繰り越しなし）
- **使い切ったら API は止まる（契約の料金には請求されない）**。購入したクレジットや自動チャージがあれば、そちらに移る
- 当社の契約がどれかは、この環境からは確認できない（**未確認**。オーナーの確認が必要）

→ もし Max・Ultra・Team なら：**支払い方法を登録せず・クレジットを購入せず・自動チャージをオフ**にすれば、追加支出は仕組み上0円で、上限は付属クレジットの額で止まる。これが「開発 AI から独立した歯止め」として最も強い（AI がコードを変えても、Console の残高以上は使えない）。

**独立した権限での管理**：ハッシュ照合とコード検査は「開発 AI の誤り」を防ぐもの。AI が意図的にワークフローを書き換えれば外せるので、それだけに頼らない。本当の歯止めは次の2つ（どちらもオーナーだけが変えられる）：
1. Anthropic Console：付属クレジットだけを使う（支払い方法なし・自動チャージなし）。または専用のワークスペースに月の使用上限を付け、そのワークスペースの API キーだけを渡す
2. GitHub の Secrets・Variables：ANTHROPIC_API_KEY・AI_BUDGET_SHA256・AI_KILL_SWITCH（AI の GitHub 連携は変数を書き換えられない）

## 4. 収益化：既存商品の分析と実行した改善
Dataset Merge & Dedup（Apify Store の公開 API、2026-11-27 実測）

| 競合 | 30日利用者 | 料金 | 題名の特徴 |
|---|---|---|---|

| 当社 | 0 | $0.0002／件（最安） | — |

発見されない原因（事実と推測）
- 【事実】「merge datasets」「deduplicate」「remove duplicates」「dedup」の検索で、当社は上位に出ない。上位は saliga・tidydata・humble-echidna
- 【推測】公開から1日未満で、品質スコアの「人気・実績」がまだ無い（他人の実行0件のため成功率も0.0%表示）
- 【事実】利用が多い有料の競合3本のうち2本は、題名で **CSV・Excel** を扱えることを示している。当社は Apify のデータセットしか読めなかった
- 【事実】Apify の無料プランの利用者は作者の売上にならない（公式）。有料プランの利用者に選ばれる必要がある

実行した改善（手元で試験済み、**公開版への反映はオーナー承認待ち**）
- **CSV・TSV・JSON・JSON Lines のファイルを URL で読み込む機能**を追加（区切り文字の自動判別、引用符・改行・BOM 対応、100MB まで）。単体試験・通し試験（ローカルの HTTP サーバーで CSV と JSON を結合、404・不正な URL で失敗すること）すべて合格
- 説明・SEO 説明・README に「CSV / JSON files」を追加（SEO 説明141字）。Apify 上の試験にも CSV の例を追加（公開リポジトリの見本ファイル）
