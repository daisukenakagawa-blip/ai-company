期間：出品から14日。成功＝外部の購入1件以上。撤退＝14日で購入0（閲覧数も記録し「見られていない」か「見られて買われない」かを分ける）

## オーナーの作業

### 1. 開店（約30分、1回だけ）
1. https://booth.pm/ を開き、pixiv ID でログイン（無ければ作成）
2. 「ショップを開設」→ ショップ名は **GENHAYL** を推奨
3. 売上の振込先の口座を登録（BOOTH の画面の指示どおり）

### 2. 出品（1点10分 × 2）
1. BOOTH の管理画面 →「商品管理」→「商品を登録」→ 種類は **ダウンロード商品**
2. 商品名・説明・価格は下の文をそのまま貼る。画像は表紙の画像
3. ダウンロードファイル：GitHub の Actions の画面から、最新の「Data products for BOOTH」の実行 → 下の「Artifacts」の **booth-data-products** をダウンロード → 中の CSV と README.txt を zip にして登録（手順が分かりにくければ、私が zip の作り方を案内します）
4. 公開

### 3. 毎週の差し替え（約5分、週1回）
- 月曜の昼に新しいデータができる。ファイルを差し替える（BOOTH の出品の自動化は公式の手段が確認できていないため、今は手作業。自動化できる方法を探す）
- 14日の実証の間だけで構わない。売れなければ差し替えをやめて撤退

## 説明文

### 入札情報 週まとめ（清掃・警備、全国）　500円
官公需情報ポータルサイトに載った公告のうち、件名に「清掃」「警備」を含む直近7日分の案件を、1つの CSV（Excel でそのまま開けます）にまとめました。
列：公告日・入札書の提出期限・都道府県・機関・件名・種別・手続きの種類・公告の URL
・重複を除き、公告日の新しい順に並べています
・都道府県で絞り込めば、自社の地域の案件だけを確かめられます
ご注意
・内容は各機関の公告が正です。入札に参加する前に、必ず公告の URL から公告・仕様書を確かめてください
・官公需情報ポータルサイトに載っていない案件、件名に該当の語を含まない案件は含まれません
出典：官公需情報ポータルサイト（中小企業庁） https://www.kkj.go.jp/ （GENHAYL が加工して作成）

### 新設法人の一覧 週まとめ（全国・株式会社と合同会社）　980円
その週に新しく法人番号が指定された株式会社・合同会社の一覧を、1つの CSV（Excel でそのまま開けます）にまとめました。
列：法人番号・商号又は名称・フリガナ・法人種別・法人番号指定年月日・都道府県・市区町村・丁目番地等・郵便番号
・電話番号・メールアドレス・代表者名は含みません
ご注意
・この一覧で広告の電子メールを送る場合は、特定電子メール法（事前の同意など）に従ってください
・このデータは国税庁が作成したものではなく、内容は国税庁によって保証されたものではありません
出典：国税庁法人番号公表サイト（国税庁）（https://www.houjin-bangou.nta.go.jp/download/sabun/index.html）を加工して作成
