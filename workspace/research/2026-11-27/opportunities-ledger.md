# 事業機会の台帳（Ver.2.3、累計）— 2026-11-27

方法：AI にアイデアを考えさせるのではなく、**実際にお金が動いている市場**と**顧客の不満**から逆算した。調査はすべて無料の公開情報（調査用エージェント4本、WebSearch・WebFetch・HN の公開 API）。**有料 API は使っていない**。

確からしさ：**第三者確認**（Stripe 等の API で検証された売上・決算資料）／**自己申告**（本人の公表）／**公式**（官公庁・規格団体・事業者自身の告知）／**推計**／**未確認**。

累計：前回 24（収益モデル）＋ 今回 105（実売上35・不満35・越境と制度35）＝ **129件**（重複を除くと約120件）。

## 学び（調査の方法）
- TrustMRR の中央値 $169：成功例だけを見て判断しない
- 「監視・ステータス」型は検証済みの小規模例が売れていない（MRR $109、累計 $2,694）
- 期限つきの終了・値上げは「移行先として見つかる」経路があり、当社の集客原則と合う
- Reddit・G2・Capterra・Acquire.com・日本の App Store 検索は、この環境から読めなかった（未確認として扱う）
