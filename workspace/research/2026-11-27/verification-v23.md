## 3. GitHub の変数名の変更（AI_BUDGET_LIMITS_SHA256 → AI_BUDGET_SHA256）
- **理由**：最初の版は limits.json（上限の数字）だけを照合していた。追加検証の指示（「開発 AI による予算管理コードの変更」）に対応するため、照合の対象を **budget.py（判定のコード）・limits.json・pricing.json（料金表）の3つ**に広げた。中身が変わったので、古い値と混同しないよう名前も変えた
- **旧変数の扱い**：コードはどこからも読まない（`grep` で確認。説明の文書だけに残っていたので直した）。登録済みなら削除してよい。残っていても害はない
- **整合性**：budget.py の `manifest_sha256()` が3ファイルの SHA-256 を計算し、ai-paid.yml が `${{ vars.AI_BUDGET_SHA256 }}` を渡す。現在の値は `ops/ai_budget/budget.py` の status で確認できる
- **権限**：Variables・Secrets を設定できるのはリポジトリの管理者（オーナー）だけ。当社の AI が使う GitHub 連携は、ワークフローの手動起動すら 403 になる権限で、変数・シークレットは変えられない。ただし AI がワークフローのファイル自体を書き換えれば照合を外せるので、最後の歯止めは Anthropic Console 側の上限（または付属クレジットだけで使うこと）
