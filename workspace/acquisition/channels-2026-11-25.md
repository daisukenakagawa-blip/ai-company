## 2. Bing Webmaster Tools ＋ IndexNow

(a) 可否：可
- 【一次】Bing Webmaster Tools は Search Console からサイトをインポートでき、確認も自動で済む。"Using the import feature, you can connect your verified sites and sitemaps directly to Bing Webmaster Tools." 一度に100サイトまで https://blogs.bing.com/webmaster/september-2019/Import-sites-from-Search-Console-to-Bing-Webmaster-Tools

## 8. 利用者による自然な紹介（出力物への出所表示）と無料→有料

- 法律【一次】ステルスマーケティング告示（景品表示法）は、事業者の表示なのに広告と判別しにくいものが対象。「「事業者の表示」であることを明瞭にしなければ、告示に違反します」 https://www.caa.go.jp/policies/policy/representation/fair_labeling/faq/stealth_marketing/ → 店名を明示した「作成：○○（URL）」は事業者の表示であることが明らかなので、この告示の問題は生じにくい【推測＝専門家の確認なし】。内容は誇張しない（景品表示法の不当表示）
- 倫理・配慮【推測】
  - 宛名ラベル・封筒・送付状など**他人に送る印刷物には入れない**（受け取る人には無関係な宣伝になり、買った人の信用にも関わる）
  - 入れてよい候補：当番表・シフト表・時間割・発表会プログラム・出席率の集計表など、会の中で配られる表の余白に小さく1行
  - 無料お試しの出力には表示、**購入後の製品版は既定でオフ（または外せる）**。外せることを商品ページに明記
  - 書き出す CSV・Excel のデータ本体には入れない（取り込み先でデータを壊すため）
- 無料→有料の設計（既存の店の構造）：無料お試しで実際の手元データの一部（例：先頭 N 行）が動く → 全件・印刷・書き出しで購入。これは既存の鍵の仕組み（Fail Closed）の範囲内
- 流入の見込み：未確認。表示した URL に `?ref=print` などを付ければ、Cloudflare Web Analytics で区別して測れる（自分の操作は数えない）
- 費用0円。外部への送信ではなく商品の変更なので、AI がリポジトリで実装可能。ただし買った人の出力に関わるので、方針はオーナー承認を推奨

## 11. 承認依頼（まとめて1件）

### 依頼 #A：Bing Webmaster Tools への登録と IndexNow の自動送信
- 実施内容：①オーナーが Bing Webmaster Tools に Microsoft アカウントでログインし、Google Search Console から店のサイトをインポート（サイトマップも取り込み）。②AI が店に IndexNow のキーファイル（`<キー>.txt`）を置き、変更のあったページの URL を自動で通知するスクリプトを作り、毎朝のデプロイ後に1回実行
- 実施するサイトやサービス：Bing Webmaster Tools（https://www.bing.com/webmasters ）、IndexNow（api.indexnow.org。共有先：Bing・Yandex・Naver・Seznam・Yep・Amazon）
- 費用：0円
- 実施期間：承認日から8週間（その後に継続を判断）
- 投稿や公開の上限：IndexNow の送信は1日1回まで、変更・追加された店の URL だけ（最大でも sitemap の102件程度、上限 10,000 件／回には遠く及ばない）。店以外の URL は送らない。サイトへの公開物はキーファイル1つだけ
- 期待する効果（根拠付き）：日本の検索の約3割が Bing（StatCounter 2026年10月、ページビュー基準の第三者統計）。Bing の AI Performance レポートで Copilot・Bing の AI 要約での引用数が見られるようになる（公式ブログ）。**訪問数・売上の増加は予測できない**。まず「索引された件数」と「表示回数」を測れるようになることが効果
- 停止条件：IndexNow が 403・422・429 を返したら即停止して日報で報告。8週間で Bing の表示回数が0なら、送信は続けても工数を割かない
- 法律・規約上の確認結果：IndexNow は公式文書に沿った送信方法（キーファイルをルートに置く方式）。自分のサイトの URL だけを送るので規約上の問題なし。Bing のインポート機能は公式の確認手段

### 依頼 #B：Google Search Console の状況確認と、数値の自動取得
- 実施内容：①オーナーが Search Console で、サイトマップ送信済みか・登録済みページ数を確認し、inbox に1行で記入（例：「GSC 登録済み 40 / 102」）。②主要約10ページ（トップ、ガイド6本、商品3件）の「インデックス登録をリクエスト」をオーナーが実行。③（任意）Search Console に読み取り専用のサービスアカウントを追加し、AI が表示回数・クリック・検索語を毎朝自動で読む
- 実施するサイトやサービス：Google Search Console、（③のみ）Google Cloud のプロジェクトと Search Console API
- 費用：0円（③の API も無料。Google Cloud の有料機能は使わない）
- 実施期間：①②は1回。③は承認日から継続（不要になれば権限を外す）
- 投稿や公開の上限：登録リクエストは1ページ1回まで（公式に「何度もリクエストしても早くならない」）。Indexing API は使わない（求人・ライブ配信専用と公式に明記）
- 期待する効果：記録の食い違い（登録済みか未設定か）が解消され、どのページが検索に出ているか、どの検索語で表示されたかが分かる。これにより、次のガイド記事を実際の検索語に基づいて選べる。**表示・訪問の増加は保証されない**（公式に「まったく表示されないこともあります」）
- 停止条件：③で不要な権限を求められる場合は中止（読み取り専用のみ）
- 法律・規約上の確認結果：いずれも Google の公式の手段。キーは環境変数に置き、リポジトリやメモに書かない
