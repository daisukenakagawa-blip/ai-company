# 公開リポジトリ『kyotei-ai-record』の中身（そのまま使える一式）

担当：product ／ 作成：2026-11-19
#11（公開リポジトリを作る）が終わったら、AIがこの内容でファイルを置きます。オーナーの作業は「空のリポジトリを作る」だけです。

## フォルダ構成
```
kyotei-ai-record/
├─ README.md            ← 下の文面
├─ index.html           ← 成績ページ（毎日AIが更新）
├─ scorecard.json       ← 成績の集計（予想・記録時刻・ハッシュ・結果のみ）
└─ picks/
   └─ 2026-11-19.jsonl  ← その日の予想。締切前に1レース1行ずつ追記（#12 承認後）
```
置かないもの：公式サイトのオッズ表・出走表などの生データ、モデルの中身、学習データ。

## picks/日付.jsonl の1行の形
```json
{"date":"2026-11-19","venue":"桐生","race_no":11,"deadline":"20:07","decided_at":"2026-11-19T20:02:11+09:00","model":"v2.3","picks":[{"combo":"2-6-4","hash":"..."}]}
```
- この1行が、締切前の時刻で GitHub のコミット履歴に残る → **第三者が「締切後に書き換えていない」ことを確認できる**
- 確率・期待値などの内部の数値は載せない（有料会員向けに残す）

## README.md の文面
```markdown
# 後出しできないAI競艇予想 — 記録庫

AIが出したボートレースの予想を、**締切前に**ここへ記録しています。
外れも含めて、全部そのまま残します。

## なぜ「後出しできない」のか
- 予想は締切前に `picks/日付.jsonl` に追記され、GitHub のコミット時刻が残ります
- コミット履歴は誰でも見られるので、あとから当たった予想だけを足すことはできません
- 各買い目にはハッシュ値を付けて、内容の書き換えを検出できるようにしています

## 成績
`index.html`（成績ページ）と `scorecard.json` を毎日更新します。
成績は「各買い目100円の仮想購入」で計算しています。

## ご注意
- これはAIの予想の記録で、舟券の購入をすすめるものではありません
- ボートレースの払戻率は約75%で、長期的に利益が出ることは保証されません
- 舟券の購入は20歳以上の方に限られます。無理のない範囲で楽しんでください
```

## #12（自動書き込み）を実装するときの安全策（法務指摘への対応）
1. 既存のワークフローは**1行も書き換えない**。最後に「公開側へ書き込む」手順を**別ジョブ**として足す
2. その手順が失敗しても、本体の判定と台帳には影響しない（`continue-on-error: true`）
3. 公開側に送るのは、上の1行の項目だけ（生データ・確率は送らない）
4. 追加する前に、ワークフローのファイルをバックアップとして別名で保存する
5. 書き込み用の鍵は、kyotei-ai-record にだけ書ける権限に限定する（オーナーが発行）
